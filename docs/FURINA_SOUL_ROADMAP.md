# Furina Soul Engine 长期路线图

> 一切以陪伴连续性、记忆保真度、情绪一致性、关系成长为准绳；不追赶高端模型能力。

## 版本里程碑

| 版本 | 主题 | 内容 |
| --- | --- | --- |
| V1（已完成） | 人格 Prompt + 静态情绪 | 心情系统、惰性扫描、人格丰满化、灵魂架构冻结 |
| V1.1（已完成） | 人格运行系统第一版 | furina-soul：六维情绪、关系阶段、三类记忆+评分、价值观/行为意图、动态注入 |
| V2（已完成） | 人格运行系统完整版 | Soul 入 core 管道、关系可解释、记忆 LLM 抽取、主动性 Engine、测试报告解析 |
| V3（进行中） | Desktop 表现层 | React/Tauri UI ✅、TTS + Qwen ASR ✅、VRM Avatar ✅；口型、动作和安装发布流程待完善 |
| V4（规划） | 生态层 | 多模型路由、3D Avatar、Multi-Agent（共享记忆、独立人格实例） |

## 灵魂能力演进

### 情绪
- V1：离散心情（6 种 × 强度）
- V1.1：六维连续状态 + 派生心情 ✅
- V2：情绪惯性显式化、情绪记忆回放（当前情绪唤起相关记忆）
- V3+：情绪语音/表情输出（Voice/3D Avatar 消费同一状态）

### 关系
- V1.1：信任值驱动五阶段 + 里程碑 ✅
- V2：可解释升级（记录"因何事件升级"）、用户画像（Semantic 记忆聚合）
- V3+：长期陪伴的纪念日、共同经历时间线

### 记忆
- V1.1：三类记忆 + 重要性评分 + top-k 检索 ✅
- V2：LLM 抽取/去重/合并、容量与遗忘策略、按类型清空接口
- V3+：语义索引（可扩展为向量检索，但本地优先）

### 主动行为
- V1.1：Time checkin（久别问候）✅
- V2：Environment（长时间工作/测试反复失败）、Memory（用户目标到期追问）+ cooldown
- V3+：语音主动开口、Avatar 表情事件

### 注入管道
- V1.1：通过 `PromptContextProvider` 注入 Agent Core ✅
- V2：core `PromptContextProvider` 管道（run/chat/GUI 统一）
- V3+：按终端能力裁剪注入块（文本/语音/视觉）

## 设计约束（长期有效）

1. Soul Engine 不拥有系统权限、不直接执行工具；
2. 工具调用必须经过 Agent Runtime；
3. 记忆属于用户私人数据：禁止上传、禁止进入 Git（已 gitignore）；
4. 不复制官方剧情文本、不保存官方语音、不训练官方数据；
5. 人格数据版本化（yaml in git），改动走测试；
6. 展示层（Voice/3D Avatar）只消费 Soul State，不污染 Soul Core。

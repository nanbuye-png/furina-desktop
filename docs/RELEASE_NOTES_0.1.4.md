# Furina Desktop v0.1.4

## 本次更新

- 稳定真实长任务的检查点、自动续跑和停滞恢复流程。
- 增加 Agent 自检、经验记录与受审批保护的自身改进提案能力。
- 完善 Avatar 音频级口型同步与 Motion 运行时。

## 升级说明

便携版升级时只替换程序、Sidecar、默认资源和 Persona；请保留现有 `data/.furina` 目录，其中包含本地配置、密钥、Avatar、记忆和关系数据。

本版本不会自动修改、提交、发布或更新自身代码；任何自身改进提案仍需要用户明确审批。
